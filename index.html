01

快速開始

BeautifulSoup 是 Python 的 HTML/XML 解析工具，適合把複雜的標籤結構轉成容易操作的 Python 物件。

INSTALL安裝套件

在終端機執行 pip install beautifulsoup4。若要發送 HTTP 請求，可另外安裝 requests。

IMPORT載入套件

從 bs4 匯入 BeautifulSoup 類別，名稱裡的 4 代表 BeautifulSoup 第四代 API。

INPUT準備 HTML

可以解析字串、檔案內容，或 requests.get(url).text 取得的網頁原始碼。

terminal
pip install beautifulsoup4 requests
02

解析文件

建立 soup 物件之後，就能像走訪樹狀結構一樣讀取標籤、屬性與文字。

parse.py
from bs4 import BeautifulSoup

html = """<html>
  <head><title>我的網站</title></head>
  <body><h1 class='title'>Hello!</h1></body>
</html>"""

soup = BeautifulSoup(html, "html.parser")
print(soup.title)       # <title>我的網站</title>
print(soup.title.text)  # 我的網站
print(soup.h1['class'])  # ['title']
選擇解析器

html.parser 不需額外安裝，適合一般用途。若遇到破損 HTML，可考慮 lxml；解析 XML 則使用 xml。

03

尋找元素

最常用的兩個方法是 find() 找第一個結果，以及 find_all() 找出所有符合項目。

find.py
# 找第一個 h1
title = soup.find('h1')

# 依標籤與 class 找所有卡片
cards = soup.find_all('article', class_='card')

# 依 id 找元素；CSS class 要用 class_
menu = soup.find(id='main-menu')

# CSS selector：彈性最高
links = soup.select('nav a[href]')
find vs find_all

find 找不到時回傳 None；find_all 找不到時回傳空的 ResultSet，迭代前不必特別判斷。

CSS selector

.card 找 class、#header 找 id、ul > li 找直接子元素，語法與 CSS 相同。

條件過濾

可傳入正規表示式、函式或多個屬性條件，精準篩掉不需要的元素。

04

擷取資料

找到標籤只是開始。接著取出乾淨的文字、連結與圖片網址，並整理成資料結構。

容易踩雷

text = tag.text

更穩定的寫法

text = tag.get_text(strip=True)
extract.py
for card in soup.select('.card'):
    name = card.select_one('h2').get_text(strip=True)
    link = card.select_one('a').get('href')
    image = card.select_one('img').get('src')
    data.append({'name': name, 'link': link, 'image': image})
屬性取得

用 tag['href'] 取值時，屬性不存在會發生 KeyError；用 tag.get('href') 則會安全地回傳 None。

05

進階技巧

處理真實網站時，資料通常不會整齊地躺在一個標籤裡。這些技巧能讓程式更可靠。

NAVIGATE走訪父子節點

tag.parent 往上、tag.children 往下、tag.next_sibling 找相鄰節點。

CLEAN移除不需要的標籤

呼叫 tag.decompose() 徹底刪除 script、style 或廣告元素，再擷取文字。

SAVE輸出結構化資料

將結果放進 list of dict，再用 csv 或 json 模組寫入檔案，方便後續分析。

一個實用的 requests + BeautifulSoup 流程

scrape.py
import requests
from bs4 import BeautifulSoup

response = requests.get(url, timeout=10)
response.raise_for_status()
soup = BeautifulSoup(response.text, 'html.parser')

# 尊重網站 robots.txt、服務條款與請求頻率
items = [
    {'title': item.get_text(strip=True)}
    for item in soup.select('.product-title')
]
